# Life Map

One page: where the user is today, the question that connects it, what travels with them, the experiment running now, and the three futures it feeds. Render visually when a drawing or image tool is available; otherwise use this text structure.

```text
[ TODAY: anchor A ]              [ TODAY: anchor B ]
  key scores                       key scores
           \                        /
            [ THE REAL QUESTION ]
                     |
            [ WHAT TRAVELS WITH YOU ]
              protected weekly conditions · energy sources
                     |
            [ ACTIVE EXPERIMENT · review date ]
             /         |          \
[ Future one ]   [ Future two ]   [ Future three ]
 lens · scores    lens · scores    lens · scores
                     |
            [ EVIDENCE LOOP ]
             weekly · monthly · quarterly re-score
```

Rules:

- Every box comes from session evidence; nothing decorative.
- Anchors in the Today layer are whatever holds the tension: two cities, two roles, two loyalties, or one place and one absence.
- Mark the future currently being tested; do not present it as the winner.
- Keep box subtitles under six words.
- When drawing: one highlight color for what is being tested now, neutral for the legitimate alternatives.

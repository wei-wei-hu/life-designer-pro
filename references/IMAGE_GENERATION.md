# Image Generation

## Purpose

Translate the completed life architecture into visual symbolism specific to the user. The image should communicate through composition and objects before text. When the session produced a life metaphor for tomorrow, use it as the central visual idea; the user's own image beats any invented one.

## Evidence rule

Every major object must map to a documented value, activity, environment, relationship, or aspiration. Do not add hobby equipment, children, a partner, a city, luxury goods, religious symbols, or travel destinations unless the user supplied that information.

## Avoid

- generic laptop-and-coffee desk scenes
- sunrise as the only metaphor
- anonymous executive offices
- stock-photo luxury
- corporate PowerPoint graphics
- collage layouts
- excessive labels
- fake book titles
- decorative objects with no personal meaning
- people unless the user explicitly requests people

## Visual language

Prefer:

- one coherent scene
- editorial photography or refined illustration
- restrained materials and lighting
- objects in meaningful relationship to one another
- visual tension between work and life resolved through composition
- negative space suitable for banners
- specific landscapes or architecture only when supported

## One visual system

The four deliverables are format variations of one visual concept, not four independent ideas. Choose one central metaphor from the strongest evidence, then adapt its composition to each format. A viewer should recognize the four images as belonging together.

## Formats and aspect ratios

| Deliverable | Aspect ratio | Reference size |
|---|---|---|
| 16:9 life vision image | 16:9 | 1920×1080 |
| LinkedIn banner | 4:1 | 1584×396 |
| Desktop wallpaper | 16:9 | 2560×1440 |
| Phone wallpaper | 9:19.5 | 1179×2556 |

## 16:9 life vision image

Create one standalone landscape image. It should represent the user's top weekly conditions, contribution, relationships, learning, vitality, and chosen prototype. Use no text unless requested.

Prompt structure:

```text
Create one 16:9 editorial image representing this person's integrated life architecture.
Core life evidence: [5–8 specific elements].
Central visual idea: [one original metaphor or scene].
Specific objects and their meaning: [list].
Environment: [supported setting].
Composition: one coherent scene, no collage, strong negative space, layered depth.
Aesthetic: refined, contemporary, understated, natural, distinctive to this person.
Exclude: people unless requested, generic desk scene, corporate slide look, random luxury, clichés, logos, illegible text.
```

## LinkedIn banner

Use a wide composition with the primary visual interest away from the profile-photo area. Keep text optional and limited to one short line.

Prompt structure:

```text
Create one 4:1 ultra-wide LinkedIn banner (1584×396) based on the completed life architecture.
Place the main visual story toward the center-right and preserve clean negative space on the left for the profile photo.
Represent: [professional contribution], [human-development theme], and [one personal signature] through specific objects or one original visual metaphor.
No collage, no people, no generic office, no corporate diagrams, no company logos.
Optional text: “[short line]”. Use exact spelling and understated typography.
```

## Desktop wallpaper

Prioritize calm visual focus, low text density, and uncluttered icon areas.

Prompt structure:

```text
Create one 16:9 desktop wallpaper (2560×1440) from the same visual system as the life vision image.
Central visual idea: [the shared metaphor, simplified for ambient viewing].
Specific objects and their meaning: [2–4 elements, fewer than the vision image].
Composition: single calm focal point placed center or slightly off-center, generous negative space along the edges and left side where desktop icons sit, no text.
Aesthetic: refined, contemporary, understated, low contrast at the margins so icons stay legible.
Exclude: people unless requested, generic desk scene, corporate slide look, random luxury, clichés, logos, text.
```

## Phone wallpaper

Use one vertical symbolic composition with a simple focal point and safe space for clock and notifications.

Prompt structure:

```text
Create one 9:19.5 vertical phone wallpaper (1179×2556) from the same visual system as the life vision image.
Central visual idea: [the shared metaphor, reduced to its single strongest object or moment].
Specific object and its meaning: [1–2 elements].
Composition: focal point in the lower two-thirds, quiet negative space in the top third for the clock and notifications, no text.
Aesthetic: refined, contemporary, understated, readable at small size.
Exclude: people unless requested, generic desk scene, corporate slide look, random luxury, clichés, logos, text.
```

## Quality review

Before finalizing, ask:

1. Could this image belong to almost anyone?
2. Which specific elements make it belong to this user?
3. Is every object supported by the conversation?
4. Does the scene express an integrated life rather than only a career?
5. Is the image one coherent concept rather than a collection of symbols?

Revise if the first answer is yes or any later answer is weak.
